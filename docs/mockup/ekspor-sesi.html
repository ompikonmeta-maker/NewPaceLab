X2 · Ekspor lengkap untuk analisa sangat dalam


Dobel-klik Ekspor Sesi.bat (atau python pacelab.py ekspor 2026-10-27), isi tanggal. Hasilnya satu file zip yang bisa diunggah ke Claude.



  
ekspor/NewPaceLab_2026-10-27.zip
├─ ringkasan.md          (sama dengan X1)
├─ taofik_per_detik.csv  (waktu, jarak, HR, pace,
│                         cadence, elevasi, power …)
├─ taofik_lap.csv
├─ taofik_asli.fit       (file asli dari jam)
├─ reza_per_detik.csv
├─ reza_lap.csv

  • Koordinat GPS tidak dimasukkan ke CSV (privasi); FIT asli tetap memuatnya — bisa dimatikan dengan pilihan “tanpa FIT”.
