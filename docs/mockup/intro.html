Mockup: intro NewPaceLab

Data rekaan. Intro diputar di atas dashboard (gambar sketsa di belakang). Klik di mana saja atau tekan tombol apa pun untuk melewati.

Menurut saya, intro NewPaceLab harus…

  • Bercerita inti tool dalam sekali lihat: dua pelari, satu garis finis 42K, hitung mundur hari. Bukan logo besar.
  • Singkat dan bisa dilewati: ±2 detik, klik / tombol apa pun langsung masuk. Dashboard dibuka hampir tiap hari; intro tidak boleh menghalangi.
  • Berubah menjadi dashboard, bukan layar terpisah: angka hari dan garis program "mendarat" di tempatnya di header.
  • Pakai angka asli dari data (hari lagi, minggu ke berapa, lampu pagi), bukan slogan.
  • Tidak setiap kali dibuka: sekali sehari, atau setelah Update membawa lari baru. Tanpa animasi kalau Windows diatur "kurangi gerakan". Tetap offline (tanpa font / gambar dari internet).
